# 🦝 Raccoon Tool PRO

**Super Roll Tool för CSGORoll**  
Ett smart Chrome-tillägg med inbyggd kalkylator, filtersökning för knivar, valutakonvertering, procenter, alerts m.m.

---

## 🔧 Funktioner

- ✅ **Inventory Tools** – Snabbåtkomst till inventory, trade & API key.
- 🔍 **Knife Finder** – Filtrera knivar & skins och hitta deals.
- 💰 **Coin Converter** – Konvertera coins till EUR & SEK.
- 📉 **Bargain Calculator** – Räkna ut vinster och prisförändringar.
- ⚙️ **Glow Options** – Anpassa filter som 🔥 Glow, 🔊 Alert, 🚨 Blink.
- 🧠 **Scout Mode** – Visa info direkt på korten automatiskt.
- 💸 **Profit Potential** – Se om item har vinstmarginal.
- ⚡ **Insta Buy** – Köp snabbt via kortkommando.

## 💡 Tips

- 🔭 Håll in `CTRL + SHIFT` på ett itemkort för att få info.
- ➗ Tryck på förstoringsglaset för att visa procent i popup.
- ⚡ Använd `CTRL + SHIFT + M1` för att instaköpa.
